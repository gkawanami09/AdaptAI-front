# Endpoints utilizados

GET /aluno/redacao/temas

GET /aluno/redacao/temas/{slug}

POST /aluno/redacao/temas/{slug}/envios

GET /aluno/redacao/envios/{envioId}   (consulta status/resultado da correção feita pela IA)

---

## GET /aluno/redacao/temas

Retorna a lista de todos os temas de redação disponíveis, para a página de listagem (`/redacao`). A navegação para cada tema deve usar o `slug` (nunca o `id`).

### Parâmetros

Nenhum.

### Payload

Nenhum (GET).

### Response esperado

```json
{
  "temas": [
    {
      "id": "1",
      "slug": "invisibilidade-povos-indigenas",
      "titulo": "Desafios para o enfrentamento da invisibilidade dos povos indígenas no Brasil",
      "tag": "Tema ENEM 2024",
      "tag_cor": "purple",
      "descricao": "Escreva um texto dissertativo-argumentativo de 7 a 30 linhas. Apresente uma proposta de intervenção que respeite os direitos humanos."
    },
    {
      "id": "2",
      "slug": "desafios-saude-mental-jovens",
      "titulo": "Desafios para a valorização da saúde mental dos jovens no Brasil",
      "tag": "Tema ENEM 2023",
      "tag_cor": "blue",
      "descricao": "Escreva um texto dissertativo-argumentativo sobre os desafios para a valorização da saúde mental dos jovens no Brasil."
    }
  ]
}
```

`tag_cor` deve ser um dos valores: `purple`, `green`, `blue`, `teal`, `gold`, `red`, `gray`.

### Interfaces TypeScript

```ts
export type RedacaoTemaResumo = {
    id: string
    slug: string
    titulo: string
    tag: string
    tag_cor: 'purple' | 'green' | 'blue' | 'teal' | 'gold' | 'red' | 'gray'
    descricao: string
}

export type GetRedacaoTemasResponse = {
    temas: RedacaoTemaResumo[]
}
```

### Status HTTP

- `200` — sucesso
- `401` — sessão expirada / token inválido

## GET /aluno/redacao/temas/{slug}

Retorna o detalhe completo de um tema de redação para a página de escrita (`/redacao/{slug}`), localizando o tema pelo `slug` (nunca por `id`).

### Parâmetros

| Nome | Tipo | Local | Obrigatório | Descrição |
|---|---|---|---|---|
| `slug` | string | rota | Sim | Slug único do tema (ex.: `invisibilidade-povos-indigenas`). |

### Payload

Nenhum (GET).

### Response esperado

```json
{
  "slug": "invisibilidade-povos-indigenas",
  "titulo": "Desafios para o enfrentamento da invisibilidade dos povos indígenas no Brasil",
  "tag": "Tema ENEM 2024",
  "tag_cor": "purple",
  "descricao": "Escreva um texto dissertativo-argumentativo de 7 a 30 linhas. Apresente uma proposta de intervenção que respeite os direitos humanos.",
  "competencias": [
    { "number": 1, "title": "Domínio da norma culta", "description": "Gramática, ortografia e pontuação", "color": "blue" },
    { "number": 2, "title": "Compreensão da proposta", "description": "Entender e desenvolver o tema", "color": "teal" },
    { "number": 3, "title": "Seleção e organização", "description": "Argumentos e repertório sociocultural", "color": "purple" },
    { "number": 4, "title": "Mecanismos linguísticos", "description": "Coesão e coerência textual", "color": "gold" },
    { "number": 5, "title": "Proposta de intervenção", "description": "Solução detalhada e respeitosa", "color": "red" }
  ],
  "repertorios": [
    "Constituição Federal de 1988, Art. 5º — igualdade perante a lei",
    "ODS 4 da ONU — Educação de qualidade para todos",
    "Paulo Freire: 'A educação é um ato de amor'",
    "IBGE 2023: 11 milhões de analfabetos no Brasil",
    "Lei de Diretrizes e Bases da Educação (LDB)"
  ],
  "dica_ada": "Use dados do IBGE ou leis específicas para enriquecer seu repertório. Isso valoriza a Competência 3!"
}
```

`tag_cor` deve ser um dos valores: `purple`, `green`, `blue`, `teal`, `gold`, `red`, `gray`.
`competencias[].color` deve ser um dos valores: `blue`, `teal`, `purple`, `gold`, `red`.
`dica_ada` pode ser `null` caso não haja dica cadastrada para o tema.

### Interfaces TypeScript

```ts
export type CompetenciaItem = {
    number: number
    title: string
    description: string
    color: 'blue' | 'teal' | 'purple' | 'gold' | 'red'
}

export type GetRedacaoTemaResponse = {
    slug: string
    titulo: string
    tag: string
    tag_cor: 'purple' | 'green' | 'blue' | 'teal' | 'gold' | 'red' | 'gray'
    descricao: string
    competencias: CompetenciaItem[]
    repertorios: string[]
    dica_ada: string | null
}
```

### Status HTTP

- `200` — tema encontrado
- `404` — slug inexistente
- `401` — sessão expirada / token inválido

## POST /aluno/redacao/temas/{slug}/envios

Envia o texto da redação escrita pelo aluno para aquele tema. Por enquanto o backend não precisa realizar nenhuma correção — apenas persistir o envio. Quando a IA de correção estiver pronta, esta mesma resposta (ou um endpoint futuro de consulta, ex.: `GET /aluno/redacao/envios/{id}`) deverá também retornar nota e feedback.

### Parâmetros

| Nome | Tipo | Local | Obrigatório | Descrição |
|---|---|---|---|---|
| `slug` | string | rota | Sim | Slug do tema ao qual a redação pertence. |

### Payload

```json
{
  "texto": "Ao longo da história do Brasil, os povos indígenas..."
}
```

### Response esperado

```json
{
  "id": "abc123",
  "slug": "invisibilidade-povos-indigenas",
  "status": "pendente",
  "texto": "Ao longo da história do Brasil, os povos indígenas..."
}
```

`status` representa o estado do envio (ex.: `pendente` até a IA processar). Sugestão de valores: `pendente`, `corrigida`.

### Interfaces TypeScript

```ts
export type PostRedacaoEnvioParams = {
    texto: string
}

export type PostRedacaoEnvioResponse = {
    id: string
    slug: string
    status: string
    texto: string
}
```

### Status HTTP

- `200` ou `201` — envio registrado com sucesso
- `404` — slug inexistente
- `401` — sessão expirada / token inválido
- `422` — payload inválido (ex.: texto vazio)

## GET /aluno/redacao/envios/{envioId}

Retorna o status e, quando pronto, o resultado completo da correção feita pela IA para o envio identificado por `envioId` (o mesmo `id` retornado por `POST /aluno/redacao/temas/{slug}/envios`).

Usado por duas telas:
- `RedacaoProcessando` (`/redacao/{slug}/processando/{envioId}`): faz polling neste endpoint a cada 4s até `status` virar `"concluida"` (redireciona para a tela de resultado) ou `"erro"` (redireciona de volta para a página de escrita do tema).
- `RedacaoResultado` (`/redacao/{slug}/resultado/{envioId}`): busca uma vez e exibe o resultado completo.

### Parâmetros

| Nome | Tipo | Local | Obrigatório | Descrição |
|---|---|---|---|---|
| `envioId` | string | rota | Sim | Id do envio da redação (retornado pelo POST de envio). |

Nenhum (GET).

## Observações gerais

- Todos os endpoints ficam na área `/aluno` (autenticada), nunca em `/admin`.
- Autenticação via header `Authorization: Bearer {token}` (JWT), igual às demais rotas de aluno já implementadas.
- Navegação e busca de tema sempre usam `slug`, nunca `id` — exceto o fluxo de correção, que usa o `envioId` retornado pelo POST de envio (necessário pois um mesmo tema pode ter vários envios).
- Nenhuma lógica de correção por IA deve ser implementada agora — o endpoint de envio (`POST .../envios`) deve apenas registrar o texto e devolver o status `pendente`. O endpoint `GET /aluno/redacao/envios/{envioId}` é onde a IA, quando pronta, deve publicar o resultado.
